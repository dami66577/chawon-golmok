이세계 음식 타이쿤 — 캐릭터와 재료 에셋

바이브코딩러 다미와 동생의 개인 게임 제작용 그림 묶음입니다.
10×10은 시트 한 장의 열·행 개수이며, 한 장에 100개를 배치했습니다.

1. otherworld_ingredients/
   일반·판타지·선계·마계·천계·요정 재료 각 100종, 총 600종입니다.
   individual/: 재료별 48×48 투명 PNG
   sheets/: 분류별 10×10칸 투명 시트, 480×480 PNG 총 6장
   previews/: 확인하기 편하도록 확대한 배경 포함 미리보기
   재료 목록 JSON: 이름·ID·분류·시트 좌표·PNG 경로

2. shop_characters/
   손님 80명, 세이지 앞치마 점원 10명, 로즈 앞치마 점원 10명입니다.
   png_48/: 캐릭터별 48×48 투명 PNG
   png_32/: 같은 캐릭터의 32×32 투명 PNG
   characters_48_10x10.png: 480×480 시트
   characters_32_10x10.png: 320×320 시트
   characters_manifest.json: 역할·ID·좌표·발 기준점
   정면 기본 포즈만 포함되어 있습니다. 걷기·옆모습·뒷모습 프레임은 없습니다.

사용 방법
개별 PNG를 그대로 사용하거나 시트를 48×48 단위로 잘라 사용하시면 됩니다.
시트 좌표는 왼쪽 위를 (0, 0)으로 하며, 각 줄을 왼쪽에서 오른쪽 순으로 읽습니다.
도트를 확대할 때는 최근접 보간(Nearest Neighbor)을 사용하세요.
웹 Canvas에서는 imageSmoothingEnabled=false, CSS에서는 image-rendering: pixelated를 사용합니다.
미리보기에는 확인용 배경이 있지만 개별 PNG와 실제 시트 배경은 투명합니다.

제작 정보
내장 이미지 생성 도구로 도안을 만들고, 그림을 분리해 크기·여백·알파와 팔레트를 정리했습니다.
재료 이름은 이 게임을 위한 창작 명칭이며, 캐릭터 이름과 게임 내 능력치·가격·레시피는 미지정입니다.
도안 요청문은 production_notes/에 정리했습니다.
