이세계 식당 타이쿤 — 판타지 요리 추가팩 40종
============================================

구성
- 이세계·선계·마계·천계·요정 음식 각 8종, 총 40종
- 메뉴·도감용 투명 PNG 48×48: 40장
- 탁자 위에 놓는 투명 PNG 24×24: 40장
- 8열×5행 투명 시트: 크기별 1장, 총 2장
- 전체 미리보기, 한글 요리 목록, JSON 명세, 생성·검수 기록

파일
dishes/png_48/ : 48픽셀 개별 요리
dishes/png_24/ : 24픽셀 개별 요리
dishes/sheets/fantasy_dishes_8x5_48.png : 384×240 시트
dishes/sheets/fantasy_dishes_8x5_24.png : 192×120 시트
dishes/fantasy_dish_index_ko.txt : 40종 한글 이름과 설명, 대응 파일명
previews/fantasy_dishes_40_preview.png : 실제 48픽셀 에셋을 3배 확대한 미리보기
fantasy_dishes_manifest.json : 전체 ID·분류·이름·크기·파일·시트 좌표
production_notes/generation_and_validation.json : 실제 생성 프롬프트·원본 기록·검수
SHA256SUMS.txt : 파일별 해시

시트 순서
왼쪽에서 오른쪽으로 8개를 읽고 다음 행으로 내려갑니다.
칸 사이 간격과 바깥 여백은 0입니다. row와 col은 0부터 시작합니다.
1행 이세계: 용의 알 오므라이스, 용비늘 호박 그라탱, 나선버섯 크림파스타, 수정감자 크로켓, 무지개 채소 꼬치, 마력 소용돌이 수프, 골렘 돌빵, 보석열매 타르트
2행 선계: 구름 만두, 선도복숭아 찐빵, 연화 찹쌀밥, 비취죽순 국수, 비취 두부찜, 영지버섯 전골, 오색 구슬떡, 월백 달떡
3행 마계: 용암 치즈버거, 마수 스테이크, 심연 먹물파스타, 화산 돌솥밥, 악마뿔 만두, 그림자포도 롤케이크, 용암복숭아 파이, 흑요석 초콜릿케이크
4행 천계: 햇살 별볶음밥, 천사날개 생선구이, 무지개 리본파스타, 빛고리 치즈수플레, 구름층 라자냐, 별빛 콘수프, 황금꿀 링도넛, 별구름 아이스크림
5행 요정: 수정꽃 젤리, 꽃잎 딸기 케이크, 도토리 버섯수프, 요정잎 쌈밥, 반딧불 베리팬케이크, 꽃버터 나비쿠키, 이슬방울 샐러드, 꿀요정 벌집파이

사용
기존 일반 요리와 같은 48픽셀/24픽셀 규격입니다.
마법 재료의 색과 모양이 완성 음식에서도 보이도록 디자인했습니다.
같은 그림을 다른 재료 조합·이름의 레시피에 연결해 활용하셔도 됩니다.
개별 PNG를 사용하거나, 명세의 sheet 및 frame 좌표로 시트를 분할하세요.
모든 에셋 경로는 이 압축을 푼 최상위 폴더를 기준으로 합니다.
픽셀 윤곽을 유지하려면 화면 확대 시 최근접 보간을 사용하세요.

제작·검수
이미지 생성 도구로 만든 원화를 분리하고, 크기를 유지하며 최근접 축소했습니다.
바깥 배경은 투명하며 알파는 0/255, 개별 PNG는 최대 48색입니다.
48픽셀 그림은 최대 42×42 영역에 들어가며 둘레에 투명 여백이 있습니다.
40종 고유 ID, 두 크기의 개별 그림 80장, 시트와 개별 PNG 일치를 확인했습니다.
미리보기에는 보기 편한 크림색 배경을 넣었습니다.
