2. 가게 규격
---------------
기본 바닥 칸은 48×48픽셀입니다. 기존 48픽셀 손님·직원과 맞춘 규격입니다.
가구는 수평 모서리와 수직 깊이 방향을 가진 직교 3/4 시점입니다.

바닥                  48×48
일반 벽, 입구문       48×96
창문 달린 벽          96×96
탁자, 조리대          96×64
위쪽·아래쪽 의자      48×48
돌화덕                96×96
문 앞 매트            96×48
허브·수정·꽃 화분     48×64

두 바닥은 완전 불투명하며 반복해서 깔 수 있습니다. 실제 3×3 반복 예시를 넣었습니다.
벽은 같은 높이로 나란히 붙여 쓰세요. 창문 벽은 가로 2칸, 일반 벽과 문은 1칸입니다.
벽 아래 기준은 y=96입니다. 가구의 바닥 기준은 manifest의 anchor에 있습니다.
가구와 UI·요리·로고의 바깥 배경은 투명합니다. 미리보기에는 구분하기 쉬운 배경색을 넣었습니다.

3. 의자 위아래에 손님 앉히기
----------------------------
탁자 좌상단을 (0,0)으로 놓았을 때, 아래 순서대로 그리면 됩니다.

순서  요소              X     Y
  1   chair_north      +24   -17
  2   손님 sit_front   +24   -32
  3   wood_table         0     0
  4   손님 sit_back    +24   +18
  5   chair_south      +24   +35

위쪽 손님은 정면이 보이고, 아래쪽 손님은 뒷모습이 보입니다.
위쪽은 의자→손님→탁자, 아래쪽은 탁자→손님→의자 뒷면 순서입니다.
손님의 이미지 바닥만으로 자동 깊이 정렬하면 같은 좌석의 순서가 바뀔 수 있으므로,
좌석 그룹의 깊이와 그룹 안의 순서를 함께 사용하세요.
examples/seating_layout.json에 실제 좌표, 오프셋, 깊이값을 넣었습니다.
examples/scene_layout.json에는 전체 가게 배치가 들어 있습니다.
모든 file 경로는 이 압축을 푼 최상위 폴더 기준입니다.

5. 요리 40종
---------------
1행: 볶음밥, 오므라이스, 카레라이스, 비빔밥, 김밥, 초밥, 리조또, 치킨덮밥
2행: 돈가스, 스테이크, 닭구이, 생선구이, 오믈렛, 미트볼, 소시지구이, 꼬치구이
3행: 토마토파스타, 크림파스타, 볶음국수, 라멘, 우동, 쌀국수, 크림수프, 고기스튜
4행: 햄버거, 샌드위치, 핫도그, 피자, 감자튀김, 크로켓, 만두, 샐러드
5행: 팬케이크, 와플, 도넛, 푸딩, 케이크, 과일파이, 아이스크림, 과일접시

8열×5행 시트는 왼쪽부터 오른쪽으로 읽은 뒤 다음 행으로 내려갑니다.
48픽셀 시트는 384×240, 24픽셀 시트는 192×120입니다. 바깥 여백·칸 간격은 없습니다.
이름과 연결할 재료·효과를 바꾸어 같은 기본 요리 그림을 여러 레시피에 활용할 수 있습니다.
재료 조합이나 수치 규칙은 포함하지 않았습니다. 그림과 ID를 원하는 게임 데이터에 연결하세요.

6. 내보내기와 검수
-------------------
원화를 개별 물체로 분리한 뒤 최근접 보간으로 게임용 크기를 만들었습니다.
UI·요리·가구의 작은 PNG는 최대 48색, 알파는 0 또는 255로 정리했습니다.
확대할 때 최근접 방식으로 표시하면 픽셀 윤곽이 유지됩니다.

65종의 ID, 파일 존재, 실제 치수, 투명도, 시트 좌표를 확인했습니다.
요리 40종은 서로 다른 그림이며, 시트와 개별 PNG가 픽셀 단위로 일치합니다.
의자는 기존 손님의 정면·뒷모습 앉기 프레임으로 실제 가림 순서를 확인했습니다.
가게 부품은 예시 장면에서 조립해 크기와 방향을 확인했습니다.

production_notes/generation_records.json의 절대 원본 경로는 제작 당시의 기록입니다.
게임에 쓸 파일은 asset_manifest.json과 각 폴더의 상대경로를 사용하시면 됩니다.
