한 명당 7포즈, 총 560프레임입니다.
1. idle_front: 정면 서기
2. walk_front_1: 정면 걷기 1
3. walk_front_2: 정면 걷기 2
4. walk_back_1: 뒷모습 걷기 1
5. walk_back_2: 뒷모습 걷기 2
6. sit_front: 정면 앉기
7. sit_back: 뒷모습 앉기

ID는 customer_001 ~ customer_080으로 이전 기본 캐릭터 팩과 같습니다.
48×48과 32×32 두 규격을 제공하므로 개별 PNG는 1,120개입니다.
인물별 가로 시트와 10명씩 7열×10행으로 묶은 시트를 두 규격으로 제공합니다.
걷기 반복의 기본 프레임 간격은 166ms입니다.
앉은 모습은 서있는 모습과 같은 배율을 유지해 키가 낮아지도록 했습니다.
의자와 탁자는 그림에 포함하지 않았으므로 게임에서 별도로 배치하시면 됩니다.

strips_48/, strips_32/: 인물별 가로 7칸 시트

공통 규격
배경은 투명이며 알파는 0 또는 255입니다.
48픽셀판의 발 기준점은 (24, 46), 32픽셀판은 (16, 30)입니다.
캐릭터별 모든 동작에 공통 축척과 최대 48색 팔레트를 적용했습니다.
확대는 최근접 보간을 사용하세요. Canvas imageSmoothingEnabled=false, CSS image-rendering: pixelated가 적합합니다.
이미지 생성 원화를 게임용 크기로 기계적으로 분리·정렬한 에셋입니다. 게임 코드에 연결하는 작업은 별도입니다.
